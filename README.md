# My Portfolio Website

A modern, responsive portfolio website built with React, Vite, Tailwind CSS, and Framer Motion to showcase my skills, projects, and journey in Machine Learning, Artificial Intelligence, and Software Engineering.

## 🚀 Technologies

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Icons

## ✨ Features

- Responsive Design
- Modern UI
- Smooth Animations
- Interactive Hero Section
- About Section
- Projects Showcase
- Contact Section
